观影手记

全部手记 #
NOTE 01开场十二分钟定基调

前十二分钟里，镜头怎么移动、角色先做什么而不是先说什么，基本决定了整部的观感。

NOTE 02留白是一种主动设计

没有解释清楚的情节，往往不是编剧偷懒，而是留给观众的判断题。

NOTE 03城市夜色是低成本的情绪装置

雨声、反光、空街道，这些元素不用台词就能把人推进同一种心境。

NOTE 04关灯前先记住一个画面

睡前能想起的镜头，通常就是这部片子里真正成立的那个理由。

NOTE 05别急着看解析

先写下自己的版本，再看别人的分析，才知道自己漏掉了多少、又多看见了多少。

NOTE 06一句话推荐比评分更有用

「推荐给谁、什么心情看、看完想聊哪一句」——三句齐了，推荐才算成立。
